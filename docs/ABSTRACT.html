NexAI: AI-Powered Personal & Developer Workspace with Utility-Metered Billing and Grounded RAG Retrieval

Domain: Applied Generative AI, RAG & Full-Stack Cloud SaaS
Architecture: Monorepo (React 18 + Vite | Node.js Express | MongoDB)
Validation Status: 227 Automated Tests Passing (Production Ready)
Model Engine: Google Gemini API (Flash 3.8 / Pro 3.1) & Pinecone Vector DB

1. Problem Statement (The Real-World Problem)

Modern developers, technical students, and knowledge workers operate across an increasingly fragmented software landscape, confronting three acute industry problems:

  • Cognitive Tool & Context Fragmentation: Knowledge workers constantly alternate between isolated single-purpose applications—chat LLMs (ChatGPT/Claude) for ad-hoc prompts, Notion for documentation, local scratchpads for code snippets, and platforms like Pramp or LeetCode for technical interview preparation. This absence of a shared context layer leads to severe cognitive overhead, duplicated manual effort, and orphaned knowledge assets.
  • Inflexible Flat-Rate AI Subscriptions: Mainstream consumer AI services mandate fixed monthly fees (~$20/mo or ₹2,000/mo) irrespective of actual inference demand. Light users and students who run 15–20 queries per month pay identical subscription fees to heavy enterprise users, creating an inequitable barrier to entry with opaque token economics.
  • "AI Wrapper" Fragility & Hallucination Drift: Typical AI wrappers pass ungrounded prompts to external models and persist unreviewed responses directly into application storage, inevitably poisoning personal knowledge bases with unchecked LLM hallucinations.

2. Proposed Solution (The NexAI Architecture)

NexAI resolves these bottlenecks by unifying conversational intelligence, personal knowledge storage, developer prompt management, and technical viva preparation into a coherent, cost-metered platform:

  • Unified Distraction-Free Canvas: A responsive, Gemini-style collapsible sidebar navigation paired with a distraction-free conversational canvas featuring real-time Server-Sent Events (SSE) streaming, Markdown rendering with syntax-highlighted code execution, and Web Speech voice dictation.
  • Polymorphic Knowledge Vault & Semantic RAG: An integrated Library accommodating notes, web bookmarks, custom file uploads, structured documents, and interview transcripts. Content is embedded into 768-dimensional vectors using Gemini Embedding models and stored in vector indexes (Pinecone / Local Vector DB) for grounded natural language semantic retrieval.
  • Prompt Vault & ChatGPT-Style Project Workspaces: A reusable prompt engineering hub with dynamic variable placeholders ({{variable}}) for instant chat injection, combined with Project Workspaces that enforce isolated system instructions and grounded multi-file source ingestion (up to 2MB capacity).
  • Interactive AI Mock Interview & Viva Simulator: A real-time interview simulator pairing hardware-accelerated CSS voice-ripple visualizers, continuous speech-to-text, progressive viva follow-up queries, and automated competency scorecards archived directly to the user's Library.
  • Token-Accurate Utility Metering & Data Sovereignty: Every AI call traverses an atomic credit gate deducting balance strictly based on real API token usage (⌈totalTokens / 100⌉), integrated with a Razorpay test-mode gateway and a strict Suggest → Review → Confirm workflow before data persistence.

3. Outcomes & Impact

  • Consolidated Single-Pane Workflow: Replaces four disparate developer tools with one unified workspace, eliminating cross-application context switching and accelerating research-to-code workflows.
  • Equitable, Cost-Transparent Utility Billing: Completely democratizes generative AI access for students and indie developers through micro-metered credit recharge tiers starting at ₹49 with strict 402 Insufficient Credit safeguards and role-gated admin usage analytics.
  • Guaranteed Groundedness & Verification: Enforces human-in-the-loop confirmation on all AI summaries and documents, eliminating hallucination propagation while providing multi-tenant vector RAG retrieval.
  • Production Hardening: Validated with 227 automated tests (127 backend, 100 frontend) achieving 100% passing status across authentication, billing idempotency, SSE streaming, and complete end-to-end user journeys.
